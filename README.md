Personal Codex/Claude skills extracted from the CHA499 / YouNavi working system.

## Skills

- `skills/navi-video-explain` - Explain a video from a URL or local file by transcribing it, selecting key frames, and producing a personalized Markdown image-and-text walkthrough.

## Install

Copy or symlink an individual skill directory into the target agent's skills directory.

For Claude:

```bash
cp -R skills/navi-video-explain ~/.claude/skills/
```

For Codex:

```bash
cp -R skills/navi-video-explain ~/.codex/skills/
```
