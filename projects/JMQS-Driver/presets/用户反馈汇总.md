## 仍需验证

- YouNavi 当前模型为什么返回 HTTP 400；Bridge 已正确显示原始错误，但未修改用户模型设置。
- 角色输出的口音和音色是否达到预期；当前播报与原始候选音效仍是两套来源。
- 从 YouNavi 侧边栏选择真实文件时，授权预览是否足够清楚。
- 对话创建耗时较长时，“正在启动 YouNavi / 正在创建”是否需要更细阶段反馈。

## 明确反模式

- 只显示没有样式和文案的箭头，让用户猜测如何启动。
- 把“任务已入队”写成“任务已完成”。
- 只有文件名没有路径，却让 Agent 扩大到整个用户目录查找。
- 用模拟输出掩盖真实 task 的失败状态。
- 自动把模型输出覆盖到人物卡的事实字段。
