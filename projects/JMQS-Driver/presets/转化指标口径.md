# Persona Driver · 转化指标口径预设

> 说明：本文件只定义指标，不伪造数值。当前 Demo 尚未接入线上埋点。

## 核心漏斗

| 指标 | 定义 | 分母 | 成功条件 |
|---|---|---|---|
| 选卡率 | 进入工作台后选中人物卡的会话占比 | 工作台有效会话 | 至少选择 1 张人物卡 |
| 插卡率 | 已选卡会话中完成插卡的占比 | 已选卡会话 | phase 进入 `locked` |
| 启动率 | 已锁定会话中触发 Driver 的占比 | locked 会话 | phase 进入 `activated` |
| 对话创建成功率 | 启动后取得完整回执的占比 | localhost 启动次数 | 同时获得 run/task/conversation ID |
| Skill 激活成功率 | 已创建对话中出现正确激活 checkpoint 的占比 | 已创建 conversation | `skill_activate.skill_name` 与人物卡 manifest 一致 |
| 最终回复成功率 | 已激活 Skill 的任务中获得完整回复的占比 | Skill 激活成功任务 | task complete 且同 task assistant reply 非空 |
| 结果查看率 | 已创建任务中用户主动检查结果的占比 | 已创建 Run | 点击“检查结果”并获得状态 |
| 恢复成功率 | error 状态中成功重新创建的占比 | error Run | 新 runId 获得完整回执 |

## 质量指标

- **输入可追溯率**：输出引用的输入中，能关联到 request.json 路径与 SHA-256 的比例。
- **虚假已读率**：没有正文或路径时，模型声称“已读文件”的任务比例；目标必须为 0。
- **目录越界率**：Agent 在未授权情况下扫描预设路径以外目录的任务比例；目标必须为 0。
- **身份一致率**：页面 persona、激活 skill、receipt skillName 三者一致的比例；目标 100%。
- **重复会话率**：同一 runId 创建多个 conversation 的比例；目标 0。
