# 假面骑事 · 产品路线图预设

> 更新时间：2026-08-19
> 用途：Persona Driver 本机真实对话测试输入。内容来自当前已实现功能，不代表生产承诺。

## 产品目标

把人物 Skill 从“可浏览的角色卡”变成“可执行的工作角色”：用户选择人物卡、指令和任务，启动 Driver 后在 YouNavi 中生成一条独立对话。

## 已验证能力

- 固定人物卡：Naval Ravikant、Elon Musk、Steve Jobs、Donald John Trump、Paul Graham。
- 四类指令：EXPLAIN、REVIEW、DECIDE、ACTION。
- 本机 Persona Navi Bridge 能创建 task/conversation，并在首条消息中显式激活对应 `/skill-name`。
- 页面能展示创建、入队、执行、完成与失败状态，并保留 conversation ID。
- 公开站保持演示模式，不读取访客 localhost、Skill 或本机文件。

## 近期里程碑

### P0 · 本机闭环

- [x] 五个人物 Skill 安装并固定版本。
- [x] Driver 启动后创建独立 YouNavi conversation。
- [x] task/conversation/message 身份回执。
- [x] 错误透传与重新检查。
- [ ] 修复当前 YouNavi 上游模型 HTTP 400，获得完整角色回复。

### P1 · 真实输入

- [x] 提供当前四份只读 Markdown 预设。
- [ ] 从 YouNavi 侧边栏由用户显式勾选真实文件。
- [ ] 发送前显示准确路径、文件数量和权限预览。
- [ ] 结果引用输入证据，不能声称读取了不存在的文件。

### P2 · 对话延续

- [ ] 从 Persona Driver 打开精确 conversation，而不是只打开 YouNavi 应用。
- [ ] 用户明确选择后复用 conversation ID 继续追问。
- [ ] 把完成回复以只读摘要投影回工作台，不写入人物卡事实层。

## 不可突破的边界

- 人物卡只保存身份、角色、简介、标签和来源；任务与输出属于单次 Run。
- 网页不能传任意 Skill 路径、shell 命令或落盘目录。
- 本机运行证据不进入公开 Sites、brain 或人物图谱真源。
- 未提供正文的素材只能显示为索引，禁止模型假装已读取。
